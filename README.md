# 独立日记

本地优先的结构化日记应用。React/Vite 前端和 Fastify API 独立运行，日记直接保存到现有 Obsidian vault。

## 环境要求

关联图谱以饱满、相接的大色块表示地点。全部成员持续约束所属区域，其他节点保持位置；跨地点成员影响多个区域，父地点包住下级区域，“我”不施加流动力。Web Worker 使用固定时间步计算速度输运、黏性扩散、压力修正和墨面覆盖场，快慢拖动产生不同的推挤与滞后，快拖边缘有少量短暂墨滴。松手后余波衰减，保留成员新位置决定的分布；初始区域包络仅在成员改变时更新覆盖目标，不再逐帧生成动画。适应画布只调整视野；刷新或数据更新后重新布局。减少动态效果时直接更新，隐藏或静止时停止模拟。这是二维交互涂料近似，不改写日记或所属关系。

运行 `node scripts/check-member-ink.mjs` 检查明暗主题、层级及 500 节点性能；设置 `QA_RECORD=0` 可排除录屏开销。`node scripts/check-territory-layout.mjs` 只读实际数据，录制慢拖、快拖和反向释放，验证其他节点保持位置。录制位于 `qa/paint-videos/`。绘制或计算超预算时依次关闭飞溅、降低轮廓刷新频率、降低场精度；手机窄屏测试不代表手机实机结果。

- Node.js 22.13 或更高版本
- 可读写的 Obsidian vault，默认 `D:/prj/obsidian`


打开 `http://127.0.0.1:5173`。API 使用 `http://127.0.0.1:4319`。

## 数据位置

- 每日日记：`00_INPUT-输入池/每日记录`
- 独立周复盘：`01_UNDERSTAND-理解层/周复盘/独立日记`

## AI 智能拆分与周总结

配置 `AI_API_KEY`、兼容的 `AI_API_URL` 和 `AI_MODEL` 后，“智能拆分”会把当前输入的一句话发送给该服务，识别人、地点、活动与食物，并为新实体建议 1-3 个标签；失败时自动回退到本地规则。界面会在调用前明确提示。

只有将 `AI_AUTO_SUMMARY` 设为 `true`，定时周总结才会向外部 API 发送本周正文；否则使用本地规则版。密钥只应存放在已忽略的 `.env`，不要提交到版本库。

## 当前安全边界

快速记录会建议事实、新知、输入或灵感类型，以及原句中明确的分钟时间。确认前可修改时间和类型；事实实体详情可展开编辑。新知、输入与灵感以带时间的正文追加到对应栏目。

关联页搜索结果可点击定位节点，实体日期可直接切换日记。日期节点详情中的“在 Obsidian 打开”使用本地 Obsidian URI 打开已保存的文件，需要本机已安装 Obsidian。

关联图默认显示“我”和人物、地点、活动、食物，同类同名实体跨日期合并。地点用墨迹和名称锚点表示，事件越多面积越大；这是一张示意地图，不表达真实地理位置。多个地点的事件分别计入各地点，无地点的事件进入“未标注地点”区域。

图谱使用纯色背景，每个地点是一团从成员位置向外晕开的彩墨；相邻墨滴在重叠处混色，地点归属与事件计数不变。工具栏的“地图配色”可修改背景和各地点颜色，刷新后保留在当前浏览器；“恢复默认配色”重置设置。旧版配色保留地点颜色，海水背景设置不再沿用。配色不修改 Obsidian 文件。减少动态效果时墨滴静止；浏览器不支持 WebGL 时使用柔和渐变墨滴回退。

实体在同一事件中共同出现就直接连线，每对实体只保留一条共现线；同一事件重复提及只算一次，同一天的不同事件分别计数。次数越多线越深、越粗，采用有上限的对数映射，选中时仍保留强弱差异；悬停连线查看准确的共同事件数。“我”的记录关系使用较淡的辅助线。实体名称默认在参与至少两个事件时显示，单次实体在悬停、聚焦、点选、拖动或搜索时显示；“我”和地点名称始终可见。筛选器可开启事件节点、日期、事物或行动关联，也可切换原有事件图谱；这些功能默认关闭，显示事件节点不改变共现计数。图谱和面积从日记重建，不改变 Markdown 格式。

图谱验收：启动前端预览后运行 `node scripts/check-ink-graph.mjs`（默认地址 `http://127.0.0.1:4182`，可通过 `QA_URL` 指定）。全部 API 使用测试数据，覆盖三种屏宽和明暗主题，截图输出到 `qa/ink-*.png`，不会写入知识库。

服务只监听 `127.0.0.1`，没有登录功能。请勿直接暴露到公网；远端部署将在本地验收完成后单独加固。
# 每日小票

点击日期栏下方的“每日小票 · 查看收藏”，查看当前日期的小票；切换顶部日期可翻看其他天。事实按事件生成，新知、输入、灵感及今日备注按空行分段。时间与事件备注保留在票面。

新增非空记录成功保存后显示出纸提示，点击即可进入当日收藏。首次读取、编辑已有条目或删除条目不会重复打印；小票由日记即时生成，不建立第二份数据库，删除原记录也会移除对应小票。

可保存单张 PNG 或导出整日长图；超长内容分成多张图片（浏览器可能要求允许多个下载）。导出只在本地完成，未保存或冲突时禁用导出。支持关闭打印提示、重播动画和系统减少动态效果。
# 计划与日记

桌面左栏、手机顶部提供「日记 / 计划」两个主入口。日记继续按日期浏览事实、新知、输入、灵感、关联和每日小票；计划独立按现实上海日期统计，不跟随正在浏览的日记日期。切换工作区保留输入、筛选和日记草稿。

计划支持逾期、今日、即将开始、已完成统计，今日／即将开始／全部／已完成及回收站筛选，并可筛选来源和清单。截止日期优先，旧计划日期兼容；今日已过明确截止时间也计入逾期。无日期计划在全部中显示。保留编辑、优先级、标签、子任务、取消、删除和恢复。

计划仍写在 Markdown 的 `## 待办清单`，使用 Obsidian 原生复选框及已有元数据注释，全部扩展字段写回；不迁移历史数据。恢复计划或将完成状态改为待开始／进行中时，删除其关联的完成事实并清除完成时间；再次完成会生成新的事实。其他日记内容不受影响。

统一录入通过 `POST /api/capture/parse` 返回共享 `CaptureDraft[]`；每条可编辑用途、日期、正文、标签和实体，逐条保存并独立显示结果。稳定记录 ID 与锁定的提交内容用于失败重试。已接通配置的 AI 服务，发送输入及已知名称、共享标签；失败保留原文并要求选择用途，不直接保存。 旧拆分和计划解析 API 保留兼容。

点击完成、勾选或改为已完成，会自动生成事实日记，不依赖 AI。服务端首次完成的上海日期时间决定日记归属；原定开始日期时间保存为不可变快照，说明标为原计划背景。恢复后再完成复用关联记录，不重复生成。旧「仅完成」、四栏目 completionRecord 与 fact 请求仍兼容。保存后留在计划页，点击「查看日记」定位记录，日记可返回计划。`/api/actions` 支持 `completionRecord`（目标日期、版本、栏目和正文），兼容旧 `fact` 请求；同一 `operationId` 的跨日期写入可恢复而不重复创建。

当前支持截止日历与重复排程；未增加通知或外部日历同步。

验证：`npm run build`、`npm test`；`node scripts/qa-workspaces.mjs` 使用隔离数据测试 375/768/1440 宽度和明暗主题，不访问真实知识库或真实 AI。结果与截图位于 `qa/workspaces/`。

中央＋直接打开全屏新增；AI 输入位于新增界面底部，关闭保留原文、手动内容及草稿队列。手机和桌面共用该入口，背景只保留单层全局导航。

手机页面使用固定视口框架：事实页的事件列表独立滚动，备注在列表上方，可展开编辑；无记录时不显示大空状态卡片。全站采用紫色毛玻璃表面，不支持模糊或启用减少透明效果时回退实色。浏览器验证：设置 `QA_GLASS=1` 后运行 `node scripts/qa-workspaces.mjs`，使用隔离数据覆盖不同记录数量和视口。软键盘验证采用缩小可见视口模拟，仍需手机实机确认。

进入关联后，图谱默认铺满应用视口，隐藏日期、保存、小票及侧栏，底部栏目可返回日记；无需浏览器全屏授权。图谱搜索和工具条使用浮动玻璃表面。

## 两周日程与演示知识库

应用默认进入计划两周视图，显示本周一至下周日，十四天连续纵排，共用顶部横向小时轴；切换工作区保留当前视图，重载回到两周。仍可选择四象限、窗口、列表、周和月。卡片按重要紧急红、重要不紧急紫、不重要紧急橙、均不重要灰染色；未设置时保留待分类。工作、生活及自定义类别保留文字；完成、超期、即将到期继续用独立徽标。到期不会移动象限。旧事项进入待分类区。桌面拖动手柄、手机长按手柄约 350ms，或使用“移动到…”菜单；批量归类只作用于当前筛选内待分类事项。

共享标签候选来自人物、事物、日记和计划。标签视图按任意选中标签匹配计划自身标签，不自动继承实体标签；删除视图不删除计划。共享库与视图保存于知识库系统目录，不需迁移。

运行 `npm run demo` 后访问 http://127.0.0.1:4320/ 。演示知识库位于 `data/demo/vault`，缓存位于 `data/demo/state`，使用本地模拟 AI 和独立浏览器来源。初始包含 26 个计划与最近七日日记，覆盖分类、状态、来源、完成记录及回收站；输入“模拟失败”可测试手动回退。初始化重复运行不重复生成。

`npm run demo:reset` 将现有演示目录备份为 `data/demo-backup-时间戳` 后重新初始化，只操作演示数据。正常 `npm run dev` 仍使用已有知识库配置。`node scripts/qa-plans.mjs` 在运行的演示服务上验证计划流程，测试操作只写演示知识库。

日记与计划默认使用紧凑顶部，不随工作区切换或退出全屏恢复旧的大块头部。手机通过单层底部导航切换工作区；日记60px日期栏包含日期、栏目与数量、信息入口和保存状态，新增及AI通过中央＋打开。桌面日记栏目切换位于左侧，中央只有工具栏与正文；关联和小票保留专用布局。

日记、计划、AI 草稿和关联编辑的选择、输入候选、确认与日期时间采用共享紫色玻璃控件，支持键盘操作、焦点恢复和屏幕边缘避让；颜色和文件上传保留系统能力。

计划桌面主区使用一行工具栏，合并日期范围与导航、六种视图、筛选及主题；左侧提供全部、今日、即将开始、逾期、已完成、回收站数量，以及类别和视图入口。手机使用单层底部导航、日期／视图工具栏与横向状态条；统计和类别进入筛选面板。颜色说明与“显示全部时段”也在筛选面板内。

从桌面左侧“新增类别”或手机筛选中的“＋”添加类别（名称和颜色），与工作、个人生活并列。自定义类别随知识库保存，支持筛选、新增/编辑、批量归类和拖动归类；桌面侧栏类别可接收拖入归类。

## 语音与重复日程（本地开发）

桌面计划左栏可筛选时间状态、切换日程视图及类别；中央内容固定一屏，分类窗口分别滚动，AI 录入从底部展开。周／月拖动显示跟随指针的卡片与目标预览，确认后才改期。手机分类窗口横向浏览，保留完整操作区域。

统一 AI 输入支持中文浏览器语音识别：点击麦克风、停止后整理，文字和实体标签立即可编辑，点击创建才保存；可直接描述每天／每周／每月重复规则。识别失败保留文字并要求核对；浏览器语音服务可能需要联网，部分浏览器不支持，实际麦克风和手机权限需在设备上检查。

新日记的发生时间、新计划的截止时间默认现实上海时间；原定开始仅在明确提供时填写。日期时间合并为一个控件，支持清空、仅日期。周／月视图显示的是截止时刻，拖动只改这一期的截止时间；鼠标拖动或手机长按350ms，15分钟吸附，预览确认后保存。时间与状态六个范围可在桌面左侧或手机顶部直接切换。密集日期点击日期查看全部记录，未安排项仍可访问。

每日／每周／每月计划按范围派生独立期次，月份缺少指定日时使用最后一天。每期编号稳定，单期改期不影响其他期；编辑可选择这一期或此后未完成记录，停止系列保留历史。每期完成单独入日记，恢复只删除该期关联完成事实。规则和期次信息写入已有 Markdown 元数据，不需要增加正式数据库表。列表默认展开到未来90天，可加载更多和扩展后90天；历史不删除。

`npm run demo` 构建并启动 http://127.0.0.1:4320/，使用隔离的 `data/demo/diary.sqlite` 与本地模拟AI，正式MySQL配置不变。演示入口仅绑定本机，自动使用演示用户；初始化幂等，包含七天日记和三类重复日程。`npm run demo:reset` 只重置演示目录，需先关闭演示。该演示库独立于以前的演示Markdown文件，旧文件保留。

`node scripts/qa-schedule.mjs` 检查375/768/1440宽度和明暗主题，截图与结果位于 `qa/schedule/`。语音采用模拟识别器，不代表实机验证。新增及原有存储回归测试均使用隔离内存数据库，已适配当前用户接口，不需要运行正式MySQL；数据库原生环境仍须另行检查。

## 保存可靠性与玻璃控件（本地交付）

今日备注上限20,000字符，输入、新知、灵感正文上限50,000字符；其他限制沿用契约。接近上限显示计数，超限保留完整文字并暂停保存，可点击错误定位字段。多条正文合并后也检查上限。服务返回字段路径、限制、错误代码与请求编号，日志不记录正文。登录过期可在原页面重新登录，版本冲突继续由用户选择；关联刷新失败单独重试，已经写入的日记仍显示已保存。

日期和时间在玻璃面板内编辑，支持24小时制、键盘输入、仅日期、清空、确认及取消。天气、睡眠和心情保留自定义输入，箭头显示所有预设。小票“去写一条”和输入类空状态均可直接进入编辑。底部布局统一预留安全空间。

本地入口仍是 http://127.0.0.1:4320/ ，不重置真实日记。`node scripts/qa-glass.mjs` 在模拟接口上检查保存失败、登录恢复、日期切换和玻璃控件；结果位于 `qa/glass/`。设置环境变量 `QA_FUNCTIONAL_ONLY=1` 可只做功能检查、不重新截图。验证详情见 [qa/glass/validation.md](qa/glass/validation.md)。线上未发布，微信安卓实机与实际麦克风测试仍需独立完成。

## 日记紧凑界面与即时改期预览（本地交付）

四个日记栏目的标题、记录数量和信息操作并入顶部，手动新增移至底部；正文直接接在日期工具栏下面。顶部信息编辑今日信息、来源、类型或标签，事实快捷记录和小票也从信息面板进入。空的文字栏目直接提供正文输入，有记录时点击底部新增展开；栏目切换保留草稿与滚动位置。手机内容面板填满共同区域，与底部 AI 入口保持8px间距。

周／月日程拖动跟随指针，松开立即移到目标并显示“待确认”。可以连续拖动多个日程，再点击“确认改期（N项）”统一保存，同一项可继续调整；拖回原时间或无效落点只撤销这一项。取消、Escape、切换视图或日期范围会撤销整批。保存逐项进行，失败项回位并暂停后续提交，已经成功的改期保留，剩余项继续待确认。写入成功后的刷新失败单独重试。原定开始和重复期次身份不随拖动改变。

`node scripts/qa-diary-layout.mjs` 检查375/624/768/1440宽度及明暗主题；截图和结果保存在 `qa/diary-layout/`，验证记录见 [qa/diary-layout/validation.md](qa/diary-layout/validation.md)。测试使用模拟接口，不写真实日记。`QA_FUNCTIONAL_ONLY=1` 跳过截图，`QA_WIDTH` 与 `QA_THEME` 可选定检查组合。交付继续使用隔离演示入口，不发布线上；浏览器模拟与微信安卓实机分别记录。
