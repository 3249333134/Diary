# 独立日记

本地优先的结构化日记应用。React/Vite 前端和 Fastify API 独立运行，日记直接保存到现有 Obsidian vault。

## 环境要求

关联图谱以饱满、相接的大色块表示地点。全部成员持续约束所属区域，其他节点保持位置；跨地点成员影响多个区域，父地点包住下级区域，“我”不施加流动力。Web Worker 使用固定时间步计算速度输运、黏性扩散、压力修正和墨面覆盖场，快慢拖动产生不同的推挤与滞后，快拖边缘有少量短暂墨滴。松手后余波衰减，保留成员新位置决定的分布；初始区域包络仅在成员改变时更新覆盖目标，不再逐帧生成动画。适应画布只调整视野；刷新或数据更新后重新布局。减少动态效果时直接更新，隐藏或静止时停止模拟。这是二维交互涂料近似，不改写日记或所属关系。

运行 `node scripts/check-member-ink.mjs` 检查明暗主题、层级及 500 节点性能；设置 `QA_RECORD=0` 可排除录屏开销。`node scripts/check-territory-layout.mjs` 只读实际数据，录制慢拖、快拖和反向释放，验证其他节点保持位置。录制位于 `qa/paint-videos/`。绘制或计算超预算时依次关闭飞溅、降低轮廓刷新频率、降低场精度；手机窄屏测试不代表手机实机结果。

- Node.js 22.13 或更高版本
- 可读写的 Obsidian vault，默认 `D:/prj/obsidian`

## 启动

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

打开 `http://127.0.0.1:5173`。API 使用 `http://127.0.0.1:4319`。

## 常用命令

```powershell
npm run dev
npm run build
npm test
npm start
npm run qa:screenshots
```

`qa:screenshots` 会用本机 Edge 对已启动的生产预览生成 1440px 与 375px 验收截图；如 Edge 不在默认位置，可先设置 `EDGE_PATH`。

## 数据位置

- 每日日记：`00_INPUT-输入池/每日记录`
- 独立周复盘：`01_UNDERSTAND-理解层/周复盘/独立日记`
- 独立素材：`02_CONTENT-内容引擎/素材库/独立日记`
- 全局标签：`07_SYSTEM-系统/独立日记/tags.json`

Markdown 是主数据。`data/` 只存可重建缓存和调度状态，已从版本控制排除。

## AI 智能拆分与周总结

配置 `AI_API_KEY`、兼容的 `AI_API_URL` 和 `AI_MODEL` 后，“智能拆分”会把当前输入的一句话发送给该服务，识别人、地点、活动与食物，并为新实体建议 1-3 个标签；失败时自动回退到本地规则。界面会在调用前明确提示。

只有将 `AI_AUTO_SUMMARY` 设为 `true`，定时周总结才会向外部 API 发送本周正文；否则使用本地规则版。密钥只应存放在已忽略的 `.env`，不要提交到版本库。

## 当前安全边界

快速记录会建议事实、新知、输入或灵感类型，以及原句中明确的分钟时间。确认前可修改时间和类型；事实实体详情可展开编辑。新知、输入与灵感以带时间的正文追加到对应栏目。

关联页搜索结果可点击定位节点，实体日期可直接切换日记。日期节点详情中的“在 Obsidian 打开”使用本地 Obsidian URI 打开已保存的文件，需要本机已安装 Obsidian。

关联图默认显示“我”和人物、地点、活动、食物，同类同名实体跨日期合并。地点用墨迹和名称锚点表示，事件越多面积越大；这是一张示意地图，不表达真实地理位置。多个地点的事件分别计入各地点，无地点的事件进入“未标注地点”区域。

实体在同一事件中共同出现就直接连线，次数越多线越深、越粗，同一天的不同事件分别计数。名称默认只显示出现至少两次的实体，其他名称在悬停、聚焦、点选或搜索时显示。筛选器可开启事件节点、日期、事物或行动关联，也可切换原有事件图谱；这些功能默认关闭。图谱和面积从日记重建，不改变 Markdown 格式。

图谱验收：启动前端预览后运行 `node scripts/check-ink-graph.mjs`（默认地址 `http://127.0.0.1:4182`，可通过 `QA_URL` 指定）。全部 API 使用测试数据，覆盖三种屏宽和明暗主题，截图输出到 `qa/ink-*.png`，不会写入知识库。

服务只监听 `127.0.0.1`，没有登录功能。请勿直接暴露到公网；远端部署将在本地验收完成后单独加固。
# 每日小票

点击日期栏下方的“每日小票 · 查看收藏”，查看当前日期的小票；切换顶部日期可翻看其他天。事实按事件生成，新知、输入、灵感及今日备注按空行分段。时间与事件备注保留在票面。

新增非空记录成功保存后显示出纸提示，点击即可进入当日收藏。首次读取、编辑已有条目或删除条目不会重复打印；小票由日记即时生成，不建立第二份数据库，删除原记录也会移除对应小票。

可保存单张 PNG 或导出整日长图；超长内容分成多张图片（浏览器可能要求允许多个下载）。导出只在本地完成，未保存或冲突时禁用导出。支持关闭打印提示、重播动画和系统减少动态效果。
# 待办清单

日期栏下点击“待办”进入当天清单。支持新增、可选分钟级计划时间、点击标题修改、勾选完成/恢复、删除确认及全部/未完成/已完成筛选。沿用自动保存、离线草稿和版本冲突保护。

待办写入日记的 `## 待办清单`，采用 Obsidian 原生 `- [ ]` / `- [x]` 格式。旧日记默认没有待办，无需迁移；未完成项留在原日期，不自动滚动，也不触发定时提醒。待办不加入事实关系图，但会进入当日小票，明确标记完成状态。
