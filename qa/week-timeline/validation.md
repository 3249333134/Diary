# 周／两周横向时间轴验证

本地交付入口：http://127.0.0.1:4320/ 。沿用隔离演示；没有新增接口、修改存储、重置真实日记或发布线上。

## 交付行为

- 周为7个连续日期行，两周为14行。顶部共享小时轴固定，左侧日期、星期与数量固定；横向查看时间，纵向查看日期，跨年日期包含年份。
- 默认只显示整个范围内有定时日程的小时；筛选面板仍可显示全部24小时。空日期保留60px紧凑行。定时卡片宽度固定，左侧圆点锚定精确截止时刻；密集卡片纵向分层，不表示持续时长。
- 有全天任务时显示独立全天列，没有则省略。日期栏始终可接收全天拖放。手机日期／全天列为72／112px，375px初始视口可完整显示首张148px定时卡。
- 未安排位于全部日期之后，间隔24px，默认收起，只显示数量；零项隐藏。展开内容不随时间轴横向移动，可编辑或拖入日历。预览后数量立即更新，取消后恢复。
- 横拖按15分钟吸附，纵拖改日期。多项连续预览在组件内立即换位，确认前零保存请求。拖动及待确认期间固定小时和日期行高；密集预览在行内滚动，点击日期可查看全部。
- 取消、Escape、无效落点及范围／视图／工作区切换沿用撤销规则。确认逐项保存，失败项回位、保留成功项与未提交项；版本检查、单期期次身份、原定开始时间和写入成功后的刷新提示保持原规则。
- 月视图保留原布局。紧凑日记、筛选、六种视图、分类拖放、全屏与8px底栏间距均回归。

## 结果

- `npm run build` 通过，保留原有大于500kB主包提示。
- `npm test`：33个文件、106项通过。新增横轴坐标、15分钟吸附、压缩间隔、23:45边界及密集标签分层测试；既有重复、完成入日记和恢复事实测试继续通过。
- `scripts/qa-week-timeline.mjs`：375／624／768／1280／1440 × 明暗主题，确认轮80组全部通过，无脚本异常。包括跨月跨年、空范围、全天列、同刻密集、未安排同步、键盘日期展开、冲突回位和短视口。
- `scripts/qa-fortnight.mjs`：86组通过；含多项调整、无效落点、回原时间、确认一次、版本递进、重复点击、部分失败、刷新失败及外部修改冲突。
- `scripts/qa-plan-density.mjs`：140组通过。桌面日历起点77px，900px视口中可视高度742px，相比压缩前至少增加317.5px。手机日历起点181px；正文与底部入口保持8px。无页面横向溢出。
- `scripts/qa-diary-layout.mjs`：38组通过，含模拟长按和横纵边缘自动滚动、草稿／展开／滚动位置保留、400／409及刷新失败。
- 初轮60张、确认轮70张批量截图，保存在 `initial/` 与 `confirmation/`。一次修正批次收窄手机列宽，并隔离卡片叠放层，解决待确认卡遮住固定日期的问题。独立确认审阅两项均已解决，未增加第三轮截图。

## 实测边界

浏览器为Windows Edge无头模拟，触控使用模拟长按。短视口、全屏和视口变化通过浏览器模拟，不能代替真实软键盘与微信浏览器工具栏行为。微信安卓实机、实际麦克风及语音权限本轮未实测。所有新日历写入验证使用拦截接口，不写真实日记。

`QA_FUNCTIONAL_ONLY=1` 只检查功能，`QA_CONFIRM=1` 输出确认轮；`QA_WIDTH`、`QA_THEME` 可限定组合。主要证据为 `confirmation/results.json`，相关旧回归已适配新坐标模型。
