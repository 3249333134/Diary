## 复现

运行 `npm run build`、`npm test` 后启动 `npm run demo`。`node scripts/qa-glass.mjs` 会检查并生成截图；仅复查功能时设置 `QA_FUNCTIONAL_ONLY=1`。几何检查使用 `node scripts/qa-glass-geometry.mjs`；日程回归同样支持该环境变量。模拟失败只在测试页面的请求拦截中生效，不改变演示服务或真实数据。
