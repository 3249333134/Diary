# 黏稠涂料交互验证

环境：本机 Headless Edge，375 / 768 / 1440 CSS 像素；375 是窄屏浏览器，不是手机实机。

| 数据与宽度 | 帧间隔中位数 | 帧间隔 P95 | Worker 中位数 / P95 |
|---|---:|---:|---:|
| 实际 44 节点 · 1440 | 16.7ms | 16.8ms | 3.7 / 5.6ms |
| 实际 44 节点 · 768 | 16.7ms | 16.8ms | 3.5 / 5.2ms |
| 实际 44 节点 · 375 | 16.7ms | 16.8ms | 2.6 / 3.6ms |
| 合成 500 节点 · 1440，无录屏 | 33.2ms | 49.9ms | 3.1 / 6.5ms |
| 合成 500 节点 · 768，无录屏 | 33.2ms | 50.0ms | 3.0 / 7.8ms |
| 合成 500 节点 · 375，无录屏 | 16.7ms | 33.4ms | 5.1 / 7.0ms |

500 节点桌面触发绘制降级，采样步长由 5 调整至 7，仍未达到 60fps 目标。实际数据接近 60fps。慢帧仍存在，不以中位数声称全程流畅。

验证了快慢施力差异、反向稳定、松手后继续流动并停止、墨滴消退、减少动态效果、成员覆盖与其他节点保持原位。六种宽度/主题组合的层级、保留形状和事件视图切换测试通过。

过程录像：`paint-videos/actual-1440.webm`、`actual-768.webm`、`actual-375.webm`；`fixture-*-light.webm` 包含 500 节点拖动过程，深色录像用于主题检查。
